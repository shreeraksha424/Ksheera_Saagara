# Ksheera Saagara

Ksheera Saagara is an Android application developed to support dairy farm management by helping users track income, expenses, and cattle-related information efficiently.

## Features
- Income and expense tracking
- Cattle management
- Dashboard analytics
- AI-based suggestions
- Report generation
- Firebase integration

## Technologies Used
- Kotlin
- Jetpack Compose
- Room Database
- Hilt Dependency Injection
- Firebase
- MVVM Architecture
